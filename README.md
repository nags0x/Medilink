# MediLink - Doctor Appointment System

![Healthcare Appointment System](https://img.shields.io/badge/Healthcare-Appointment_System-blue) 
![PHP Backend](https://img.shields.io/badge/Backend-PHP-purple)
![Next.js Frontend](https://img.shields.io/badge/Frontend-Next.js-black)

MediLink is a full-stack healthcare appointment system that bridges the gap between patients and doctors. It features secure authentication, seamless appointment booking, and integrated payment processing to provide a smooth and efficient healthcare experience.

---

## Features ✨

### **User Authentication** 🔒
- Login/Signup with OTP verification.
- Password reset functionality.
- Secure session management.

### **Doctor Management** 👨‍⚕️
- Add and view detailed doctor profiles.
- Search doctors by specialty or location.
- Highlight top-rated doctors.

### **Appointment System** 🗓️
- Book available time slots with ease.
- View and manage booking history.
- Calendar integration for better scheduling.

### **Payment Processing** 💳
- Razorpay integration for secure payments.
- End-to-end payment flow management.
- Order and transaction history tracking.

---

## Tech Stack 🛠️

### **Frontend:**
- Next.js (App Router)
- Tailwind CSS (Utility-first CSS framework)
- React Context API (State Management)
- Razorpay SDK (Payment Integration)

### **Backend:**
- PHP (Backend Logic)
- MySQL (Database)
- PHPMailer (Email/OTP Functionality)
- Razorpay PHP SDK (Payment Gateway)
